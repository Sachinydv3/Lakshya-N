# **App Name**: EduNav

## Core Features:

- Aptitude Quiz: Short quizzes to assess student interests and strengths.
- AI Course Suggestion Tool: Based on quiz results, an AI tool will suggest suitable subject streams and degree programs. Compare career paths based on combinations.
- Course-to-Career Mapping: Visual charts showing career paths each degree offers, including industries, sectors, exams, and higher education options.
- Nearby Colleges Directory: Location-based listing of government colleges with program details, eligibility, and facilities.
- Timeline Tracker: A system for notifications about admission dates, scholarship deadlines, and entrance tests.
- User Profiles: User profiles that track age, gender, class, and academic interests to help target suggestions.

## Style Guidelines:

- Primary color: A muted blue (#79A0C2) that evokes trust and intelligence. It's versatile and contrasts well with a light background.
- Background color: Light off-white (#F0F4F7), visibly desaturated to provide a clean, non-distracting backdrop.
- Accent color: Yellow-orange (#D48B35), approximately 30 degrees to the 'left' of blue, will draw attention to calls to action.
- Font pairing: 'PT Sans' (sans-serif) for headlines and 'Literata' (serif) for body text. 'PT Sans' offers modernity while 'Literata' enhances readability for longer text blocks.
- Use simple, clear icons to represent different degree programs and career paths.
- A clean, intuitive layout that prioritizes easy navigation and readability.
- Subtle transitions and animations to guide users through the app and provide feedback.
